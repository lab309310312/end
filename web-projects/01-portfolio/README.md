# 01 - Developer Portfolio

A responsive personal portfolio website showcasing student coursework, networking labs, and software projects.

## Features
- **Dynamic Typewriter Subtitle:** Cycles through core technologies (HTML5, CSS3, JavaScript, Java Servlets).
- **Mobile Responsive Navigation:** Accessible hamburger menu toggle for small screens.
- **Skill Progress Visuals:** CSS percentage-based animation based on `data-w` values.
- **Projects Showcase:** Highlight cards for key course projects.
- **Client-Side Form Validation:** Validates full name, email format, and message before showing confirmation.

## Files
- `index.html`: Semantic markup with hero, about, skills, projects, and contact sections.
- `style.css`: Modern CSS styling with CSS variables, responsive Flexbox/Grid layouts, and smooth transitions.
- `script.js`: Typewriter effect, navigation toggling, and form validation logic.

## Usage
Open `index.html` in any web browser.
