# 05 - Networking Quiz App

A timed quiz application testing fundamental computer networking concepts.

## Features
- **Curated Networking MCQs:** Tests topics including cabling types, OSI layer models, routing protocols, VLANs, and network diagnostics (`tracert`).
- **Timed Gameplay:** 15-second per-question countdown with an animated visual timer bar.
- **Immediate Feedback:** Highlights selected answer as correct (green) or incorrect (red) with descriptive feedback.
- **Scoring & Performance Evaluation:** Calculates overall percentage, performance tier, and offers an instant replay option.

## Files
- `index.html`: Multi-screen layout (Start, Active Quiz, Score & Results).
- `style.css`: Clean interface with animated progress bar and clear visual state cues.
- `script.js`: Question bank, interval timer engine, answer validation, and final score tally.

## Usage
Open `index.html` in any web browser.
