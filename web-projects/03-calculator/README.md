# 03 - Web Calculator

A clean, responsive browser-based calculator supporting arithmetic, percentages, and display history.

## Features
- **Standard Operations:** Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
- **Advanced Controls:** Percentage calculations (`%`), single-character backspace (`DEL`), and full reset (`AC`).
- **History Tracking:** Displays the ongoing calculation and current operand simultaneously.
- **Precision & Boundary Checks:** Handles floating-point numbers and zero-division errors gracefully.

## Files
- `index.html`: Grid layout containing display screen and numeric/operator keypad.
- `style.css`: Minimalist design with tactile button press states and monospace typography.
- `script.js`: State machine handling operand inputs, operator precedence, and evaluation logic.

## Usage
Open `index.html` in any web browser.
