# 04 - Chai & Co. Menu & Ordering System

An interactive cafe menu and shopping cart application built with vanilla JavaScript.

## Features
- **Dynamic Catalog:** Renders tea, snacks, and sweets with custom icons, pricing, and descriptions.
- **Category Tabs:** Filter products across *All*, *Tea*, *Snacks*, and *Sweets*.
- **Live Search:** Instant client-side text search across item names and descriptions.
- **Interactive Cart:**
  - Add items to cart with badge counter updates.
  - Increment, decrement, or remove items inside the cart drawer.
  - Real-time subtotal and total cost calculation.

## Files
- `index.html`: Header, category filter bar, search input, item grid, and cart drawer modal.
- `style.css`: Warm cafe-inspired palette with responsive grid layouts.
- `script.js`: Product data store, search and filter event handlers, and cart state reducer.

## Usage
Open `index.html` in any web browser.
