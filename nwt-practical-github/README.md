# NWT Practical Lab Repository

Ready-to-use examples for Network and Web Technology practicals.

| Folder | Practical | Stack |
|---|---|---|
| `06-jsp-servlet-session/` | JSP/Servlet session handling, URL rewriting, hidden fields | Java 17+, Maven, Tomcat 10.1 |
| `07-html5-css3/` | HTML5 and CSS3 responsive page | HTML, CSS |
| `08-javascript-integration/` | Interactive form validation | HTML, CSS, JavaScript |
| `09-tcp-handshake/` | TCP three-way handshake and termination simulation | Python 3 |
| `10-ruby-on-rails/` | Simple Rails task-list app | Ruby, Rails, SQLite |

## Clone
```bash
git clone https://github.com/YOUR-USERNAME/nwt-practical-lab.git
cd nwt-practical-lab
```
Open the selected folder and follow its README. Replace `YOUR-USERNAME` with your GitHub username.

**Note:** The TCP practical simulates protocol states; it does not generate real network packets.
